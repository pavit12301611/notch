# Notch design review deck

`Notch-Design-Review.pptx` is the editable design handoff for the current v8 UI.
It is a **baseline**, not a new visual proposal: open it, edit the mockups directly,
and return the `.pptx`. The next implementation pass should follow the edited deck
instead of guessing.

## What is inside

- 44 slides, 16:9, dark review theme.
- Closed / peek / open modes, all six pages, empty/loading/disabled/offline/error states.
- Settings pages, adaptive rules, motion, visibility, components and guardrails.
- `EDIT HERE` boxes on mockup slides and a decision log on slide **N41**.
- Slide → source-file mapping on slide **N42**.
- Speaker notes on every slide with source references.

All mockups are native PowerPoint shapes/text boxes (grouped by surface). There are
no embedded screenshots, so colors, spacing, labels and geometry can be edited.

## How to edit

1. Keep the slide ID (`N01`…`N44`) in the footer.
2. Select a mockup group; ungroup if you need to move one control.
3. Change shapes/text/colors/spacing directly, or write explicit values in `EDIT HERE`.
4. For a new state, duplicate the closest slide and name it `Nxx-A`.
5. Fill the decision log on **N41** and save as `.pptx`.

Useful explicit edit format:

```text
N12 / Music page
- Art: 72 → 80 px, radius 14 → 16
- Title: 14.7 → 16 px, max 2 lines
- Transport spacing: 10 → 12 px
- Keep disabled state visible
```

## Regenerate (optional)

The deck is generated by `scripts/build_design_review.py`.

```bash
python3 -m pip install python-pptx pillow
python3 scripts/build_design_review.py \
  --output design/Notch-Design-Review.pptx \
  --preview .cache/design-preview \
  --warnings .cache/design-preview/warnings.txt
```

`pillow` is only needed for the optional PNG proof previews. The PPTX itself uses
`python-pptx`. Preview images are written to `.cache/` and are not part of the deck.
